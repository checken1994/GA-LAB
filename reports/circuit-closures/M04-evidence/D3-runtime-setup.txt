## Probe-harness corrections during the session (disclosed)

1. Attempt 1-2 container env was mangled by Git Bash MSYS path conversion
   (SCP_DATA_DIR -> C:/Program Files/Git/...) — fixed with MSYS_NO_PATHCONV=1.
2. Uvicorn defaulted to loopback inside the container — fixed with SCP_HOST=0.0.0.0
   (compose sets the same value for the main deployment).
3. First P7 run sent the capability token in the X-SCP-Capability-Token header;
   hands_routes reads payload.capabilityToken from the JSON body — probe fixed
   (product behavior was correct; header-based capability injection is the
   pc_controller_routes contract, body-based is the hands_routes contract).
4. Full probe matrix re-run after each fix; final recorded run: ALL 13 PASS.
