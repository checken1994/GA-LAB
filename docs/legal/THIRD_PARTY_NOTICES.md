# SCP DNA — Third-Party Notices

This file must be completed before a public release. It is a tracking document, not a relicensing statement.

## How to use this file

List every dependency, vendored file, model, dataset, font, icon, image, generated asset, SDK, and copied snippet that is not wholly owned by the project copyright holder.

Do not claim that third-party material is licensed under the SCP component license unless the third-party license expressly permits that conclusion.

## Required review questions

For each entry, confirm:

1. The exact version or commit is recorded.
2. The source and copyright holder are identified.
3. The license text is stored or linked as required.
4. Attribution and NOTICE requirements are preserved.
5. Patent, trademark, data, model, and usage restrictions are recorded.
6. The component is compatible with the package in which it is distributed.
7. The release artifact does not accidentally include a private or unlicensed file.

## Generated and model-related materials

Generated code, model weights, datasets, benchmark files, fonts, images, and icons may have terms different from the source code. Record their provenance separately instead of assuming that the repository license covers them.

## Release gate

A release is not ready for public distribution while any required third-party entry is marked `TODO`, `UNKNOWN`, or `NOASSERTION` without an explicit maintainer decision and legal review where needed.
