# SCP documentation layout

- `README.md` remains the root entry guide.
- `docs/guides/` contains operating guides.
- `docs/archive/` contains historical audit rounds and baselines.
- `scripts/ops/` contains elevated or host-level harnesses.
- `scripts/maintenance/legacy/` contains one-off migration/patch helpers.
- Root launchers remain intentionally at root for double-click compatibility.
