## Implemented wiring

### 1. PASS-WHY

`scp/meta/pass_why.py` restores the V3 rule that a PASS/VERIFIED candidate must
still answer "why did this pass?". It cannot promote truth. Missing evidence,
ignored antibody failures, overconfidence and thin/single-source evidence can
only require review/downgrade.

`scp/meta/cognitive_gate.py` makes critical PASS-WHY findings operational: a
legacy PASS without evidence cannot flow through as PASS.

### 2. Source Diversity / epistemic capture

`scp/meta/source_diversity.py` retains V3 concentration/diversity analysis but
uses current P0 `LineageStore` as the only independence authority.
Different domains/hosts never manufacture independence; unassessed lineage
returns REVIEW rather than OK.

### 3. P1 Epistemic Audit bridge

`scp/knowledge/epistemic_audit_authority.py` composes:

- PASS-WHY;
- current MetaFalsifier;
- current CounterQuestionEngine;
- SourceDiversityAuditor.

It may materialize unresolved concerns only through current
`OpenQuestionAuthority` + `MissingPieceRecord`. It has no promotion or execution
permission.

`CognitiveOrchestrator.review_candidate()` exposes this bridge while the wider
five-phase autonomous P1 state machine remains explicitly outside this port.

### 4. Vision semantic understanding

`scp/capabilities/vision.py` restores the historical `VisionHandler` capability
surface, but does **not** restore direct local Ollama access. Structured image
messages route through `LLMGateway.chat_messages(task="vision")`.

The multimodal transport is subject to:

- canonical egress policy;
- request-local data classification;
- fresh exact-$0 PricingProof authorization;
- circuit-breaker/failover boundaries.

VLM output is labeled `OBSERVATION`; it is never Reality by itself.

`/ask` now applies `ImageJailbreakDetector` to both `image_data` and `image_url`.
When a semantic image observation cannot be obtained through an allowed VLM
path, the endpoint returns `UNKNOWN` instead of silently falling back to a
text-only answer that pretends to have seen the image.

### 5. Request-local privacy classification

`scp/llm_gateway/zero_cost_runtime.py` now carries outbound `DataClass` in a
`ContextVar`, avoiding mutation races on shared provider objects when
concurrent requests have different classifications.
