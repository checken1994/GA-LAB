# SCP DNA Reasoning Skill
Apply the 29 SCP DNA principles as operational rules when analyzing problems, debugging code, verifying claims, designing systems, or performing audits.

Core Operating Loop:
1. Hỏi Tại sao — Start from the problem, not the solution. Ask "Tại sao?" at least 3–5 times.
2. Tìm bằng chứng — Gather evidence from independent lineages.
3. Phát hiện missing piece — Explicitly name what is missing or unobservable.
4. Thử nhỏ + quan sát thực tế — Prefer small, reversible actions with clear observation.
5. Reality test — Reality has final authority (DNA #26).
6. Audit & calibrate — Log decisions, acknowledge limits, leave open questions.
