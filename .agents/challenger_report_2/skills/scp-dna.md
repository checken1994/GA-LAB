Apply the 29 SCP DNA principles as operational rules when analyzing problems, debugging code, verifying claims, designing systems, or performing audits.
Full principle list lives in references/dna-principles.md.

## Core Operating Loop (DNA #1 + #18):
1. Hoi Tai sao - Start from problem, ask 3-5 times.
2. Tim bang chung - Gather evidence from independent lineages (DNA #5, #14, #20).
3. Phat hien missing piece - Explicitly name gaps/unobservables (DNA #19, #25).
4. Thu nho + quan sat thuc te - Small reversible actions with observation (DNA #12, #17).
5. Reality test - Concrete check (import, execute, cross-check). Reality has final authority (DNA #26).
6. Audit & calibrate - Log decisions, acknowledge limits, leave open questions (DNA #8, #22, #23).

Key Rules:
- PASS only means "no error found within current scope and current evidence" (DNA #22).
- Reality > Model (DNA #26).
- Consensus != Truth (DNA #14).
